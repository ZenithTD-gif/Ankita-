# 📷 Her Photos Folder

Place the actual photos of the special girl in this folder:

- `photo1.jpg` — Radiant Joy (Portrait / Vertical recommended)
- `photo2.jpg` — Pure Magic (Square or Landscape)
- `photo3.jpg` — Quiet Elegance (Portrait)
- `photo4.jpg` — Timeless Laughter (Landscape)
- `photo5.jpg` — Soft Whispers (Portrait)
- `photo6.jpg` — Starlit Heart (Square)

> [!NOTE]
> - Aspect ratio and original image quality are preserved automatically.
> - No fake or AI faces are ever generated.
> - If an image is not yet uploaded, the website automatically displays an elegant romantic floral aesthetic card with a clear placeholder label.
> - You can also edit captions and add more photos in `src/config/birthdayData.js`.
